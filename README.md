| Projeto | Descrição | Ferramentas |

## 🛠️ Ferramentas

- **Radio Mobile**: simulação de enlaces, perfil de terreno e zona de Fresnel
- **MATLAB**: cálculos de propagação em espaço livre e gráficos
- **Excel**: orçamento dos materiais e serviços
